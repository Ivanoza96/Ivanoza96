# Work With Me

I take selected, clearly scoped software implementation work.

My best fit is a client who already has a real product, workflow, or concrete feature requirement and needs someone to turn it into a working, testable implementation.

- admin and operational modules;
- booking and workflow features;
- relational database changes and migrations;
- API integration;
- responsive/UI corrections;
- feature and regression tests.

### Flutter / Dart

- product features and application flows;

### Python / practical AI

- local-first AI prototypes;

- task/execution workflows;
- testing and verification.

## How I work

`Understand → Scope → Implement → Test → Review → Verify → Ship`

I prefer focused milestones with clear acceptance criteria. For an existing codebase, I first establish the current behavior and boundaries, then make the smallest reviewable change that solves the requested problem.

For data-sensitive or production work, I prefer isolated testing, regression checks, and an explicit rollout/rollback boundary where practical.
